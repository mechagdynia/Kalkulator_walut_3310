# Waluta 3310 v1.0.0

Pierwsze wydanie bezpłatnego kalkulatora i przelicznika walut dla przeglądarki, Androida i iOS.

## Najważniejsze funkcje

- Dwie skórki: klasyczna Retro LCD oraz kolorowa Modern.
- Kalkulator i jednoczesne przeliczanie od 2 do 8 walut.
- 30 walut, wyszukiwanie, zmiana waluty bazowej i funkcja SWAP.
- Automatyczne źródła zapasowe kursów oraz pamięć ostatnich danych offline.
- Instalowalna aplikacja PWA i projekty natywne Capacitor dla Androida oraz iOS.
- Zgłoszenie awarii do pomocy technicznej dopiero po zatwierdzeniu przez użytkownika.

## Bezpieczeństwo i jakość

- Brak backendu, kont użytkowników, reklam, analityki i sekretów w aplikacji.
- Własny parser działań bez `eval`, walidacja odpowiedzi API i restrykcyjna polityka CSP.
- Produkcyjny build nie zawiera map źródłowych.
- TypeScript, build produkcyjny i 57 testów automatycznych zakończone powodzeniem.

Kursy mają charakter informacyjny i mogą być opóźnione. Aplikacja nie udziela porad finansowych.
